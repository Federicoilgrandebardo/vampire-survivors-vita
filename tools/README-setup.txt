Vampire Survivors for PS Vita - setup tool
https://github.com/Federicoilgrandebardo/vampire-survivors-vita

This tool extracts the game data from your own copy of Vampire Survivors
and sends it to your Vita. The full guide is on the page above.

1. In Steam, open the game's Properties, then Betas. Enter the access code
   PhaserVersion2023, pick old-engine and let it download.
2. On the Vita, start an FTP server (VitaShell: press SELECT).
3. Run VampireSurvivorsSetup-Windows.exe and follow the steps on screen.
4. Install the VPK from the Releases page with VitaShell.

Windows may show "Windows protected your PC" the first time, because the
tool has no paid code signing certificate. Click "More info", then
"Run anyway". The source code is on the page above.
